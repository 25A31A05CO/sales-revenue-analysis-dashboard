# Customer Segmentation Project

## Thiranex Data Analytics Internship

### Objective
Segment customers based on demographics and purchasing behavior to identify meaningful customer groups.

### Dataset
`customer_segmentation_dataset.xlsx`

The dataset contains customer demographics, income, purchase frequency, spending, website visits, recency, and loyalty information.

### Suggested Workflow
1. Load the Excel dataset using Python/Pandas or Power BI.
2. Check missing values and data types.
3. Select relevant numerical features.
4. Standardize the features.
5. Apply K-Means clustering using scikit-learn.
6. Compare cluster characteristics.
7. Visualize the segments using scatter plots/bar charts.
8. Give each cluster a meaningful business label.

### Key Features
- Annual Income
- Total Purchases
- Total Spend
- Average Order Value
- Website Visits
- Last Purchase Days Ago
- Loyalty Years

### Expected Outcome
Identify distinct customer groups and describe their purchasing behavior. The results can support targeted marketing and customer retention strategies.

### Tools
Python, Pandas, NumPy, Matplotlib/Seaborn, Scikit-learn, or Power BI.
